# explorador-viajes y lugares Turísticos

Explorador de viajes es un proyecto integrador diseñado para consultar y visualizar información detallada sobre países alrededor del mundo. Desarrollado con JavaScript, APIs y librerías.

## Tecnologías

- HTML5
- JavaScript ES6+
- Tailwind CSS
- APIs REST
- LocalStorage
- Leaflet
- SweetAlert2
- Git
- GitHub

## Características

El proyecto permitirá:

- Consultar países desde una API REST.
- Buscar destinos.
- Filtrar destinos por continente.
- Ordenar resultados.
- Consultar información detallada.
- Visualizar la ubicación del destino en un mapa.
- Guardar destinos favoritos.
- Persistir favoritos mediante LocalStorage.

## ui.js

- map()
- template literals

## Arquitectura

La aplicación utiliza una sola página HTML y divide progresivamente la lógica JavaScript en módulos según su responsabilidad.
